ShadowScan is a lightweight, high-performance **tactical reconnaissance tool** designed for researchers and penetration testers. It transforms raw IP data into actionable intelligence through parallel scanning, service versioning, and automated risk analysis.

## 🔥 Key Overhaul Features

### 🖥️ Premium Web UI (v1.2.5)
- **Immersive Background**: Dynamic scanline grid with obsidian-cyber ambient glows.
- **Interactive Terminal**: Real-time simulation of scanning logic with progress bars.
- **Glassmorphic Components**: High-fidelity UI cards with sliding neon green border effects.
- **Responsive Core**: Fully optimized for tactical use across mobile and desktop.

### 🐚 Advanced CLI Suite
- **Interactive UX**: Live spinners and color-coded status reports for better readability.
- **Signature Engine**: Automated flagging of vulnerable service versions (Apache, FTP, etc.).
- **Rapid Recon**: Integrated WHOIS and DNS resolution piped directly into structured reports.
- **Stealth Core**: Minimal footprint with dependency validation and clean temporary data management.

## 🚀 Getting Started

### Prerequisites
Ensure your Linux or WSL environment has the following tools installed:

```bash
sudo apt-get update && sudo apt-get install nmap whois dnsutils -y
```

### Installation
Clone the repository and set appropriate permissions:

```bash
git clone https://github.com/harsh-hak/ShadowScan.git
cd ShadowScan
chmod +x vuln_scan.sh
```

---

## 🧪 Usage

### Standard Scan
Scan one or more targets sequentially with full service analysis:
```bash
./vuln_scan.sh <IP1> <IP2> ...
```

### Premium Preview (Demo Mode)
Experience the new UI and output format without needing system permissions:
```bash
./vuln_scan.sh --demo
```
